## The line

> Kid, your left hand breaks at twenty-eight and never heals right — stop waiting for it to, and teach the other one everything it knows.

## How it works

`main.py` writes that single line to `/output/entry.txt` — one line, in English, 135 characters, no explanation, no second sentence.

```bash
python3 main.py
cat /output/entry.txt
```
